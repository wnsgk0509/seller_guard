# 🛡️ 셀러가드 (SellerGuard)

> **스마트스토어 & 쿠팡 셀러 전용 1초 상표권 사전 자가진단 레이더 (크롬 확장 프로그램)**

셀러가드(SellerGuard)는 이커머스 셀러들이 상품을 등록하기 전, 상품명에 포함된 상표권 침해 및 로펌 고소 위험 키워드를 1초 만에 감별하고 자연스러운 안전 대체어로 가이드해 주는 브라우저 확장 프로그램입니다.

---

## ✨ 핵심 기능

1. **1초 위험 키워드 스캔**:
   * 그립톡, 지비츠, 레고, 나이키 등 실제 로펌 내용증명 빈출 30대 등록상표 실시간 탐색.
   * 한글 및 영문 대소문자(NIKE, nike, Griptok 등) 완벽 대응.
2. **이커머스 문맥 지능형 대체어 추천**:
   * 단순 치환으로 인한 단어 중복(예: '거치대 거치대')을 자동으로 정제하여 깔끔한 쇼핑몰 키워드로 변환.
3. **법적 방패막 온보딩 (Legal Shield Splash Screen)**:
   * 최초 실행 시 1차 자가진단 보조 도구임을 명시하고 법적 책임을 사전에 차단하는 온보딩 절차 탑재.
4. **완전한 로컬 보안**:
   * 어떠한 개인정보, 매출 데이터, 스토어 계정 정보도 외부 서버로 전송하지 않는 안전한 로컬 기반 엔진.

---

## 🚀 빠른 시작 (설치 방법)

1. 본 저장소의 코드를 다운로드(또는 `git clone`)합니다.
2. 크롬(Chrome) 브라우저를 열고 주소창에 `chrome://extensions/`를 입력합니다.
3. 우측 상단의 **[개발자 모드]**를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]**를 클릭합니다.
5. 본 저장소의 `seller_guard_extension` 폴더를 선택하면 설치가 완료됩니다!
